# Venus Launcher 6.0.0

Versión estable para Windows 10 y 11 (64 bits).

## Novedades

- Venus IA usa OpenAI como proveedor principal; la clave se configura en Administración y se guarda en el backend.
- Instance Groups comparte servidores y teclas entre instancias. Agrega historial, vista previa y opción de deshacer cambios compartidos.
- Chequeo previo de instancia para archivos, Java, espacio, cuenta, teclas y mods duplicados.
- Las actualizaciones de modpacks restauran la instantánea anterior si falla la aplicación. Se reforzó el deshacer de actualizaciones de mods.
- Soporte con IA y MCP; Ayuda rápida admite hasta 3 preguntas por minuto.
- Interfaz y panel de Administración traducidos a 14 idiomas. Se retiraron las pantallas de Points y Pass.

## Actualización

La edición instalada comprueba actualizaciones al abrir y cada cuatro horas cuando Ajustes → Privacidad → Actualizaciones automáticas está activado. Descarga 6.0.0 y la instala al cerrar Venus; también se puede buscar desde Actualizaciones. La edición portable avisa y ofrece la descarga manual.

## Limitaciones

La recuperación automática del ejecutable anterior tras una actualización del launcher que impida iniciarlo no está incluida. En ese caso, reinstalá la versión anterior desde GitHub Releases. Las traducciones agregadas siguen pendientes de revisión por hablantes nativos. La retirada de Points y Pass del backend está preparada pero todavía no se ha aplicado para permitir la transición de clientes 4.6.2.
