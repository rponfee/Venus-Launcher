# Venus Launcher 4.6.3 beta 3

Esta beta activa la búsqueda automática de actualizaciones para instalaciones
nuevas: consulta GitHub al abrir y cada cuatro horas, descarga una versión nueva
y la instala al cerrar el launcher. Se puede desactivar en Ajustes → Privacidad;
una elección previa de desactivarla se conserva. La edición instalada beta
recibirá futuras betas y la siguiente versión estable; una instalación estable
no recibirá betas. La edición portable sigue avisando y ofreciendo la descarga,
pero no puede reemplazarse mientras está abierta.

La beta 2 ya instalada necesita una actualización manual única a beta 3 si la
búsqueda automática estaba desactivada. La versión estable 4.6.2 no recibirá
esta beta de forma automática.

El backend de OpenAI aún requiere la clave en Supabase Vault y la activación de
las migraciones 0049–0052 y las funciones nuevas. La traducción integral del
panel de administración sigue pendiente en 12 idiomas. Esta beta no sustituye
la versión estable.
